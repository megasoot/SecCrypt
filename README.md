# SecCrypt

**SecCrypt** — плагин для [exteraGram](https://github.com/exteraGram) для безопасного шифрования и расшифровки сообщений.

Плагин поддерживает три формата защиты: **SEC1**, **SEC2** и **SEC3**, позволяя работать как со старыми зашифрованными сообщениями, так и с современным форматом с аутентифицированным шифрованием.

## ✨ Возможности

- 🔐 Шифрование сообщений перед отправкой
- 🔓 Расшифровка защищённых сообщений
- 🛡️ Поддержка форматов **SEC1 / SEC2 / SEC3**
- 🔎 Автоматическое определение формата защищённого сообщения
- 🔑 Защита сообщений с помощью парольной фразы
- 📋 Копирование результата расшифровки
- 💬 Отправка зашифрованных сообщений непосредственно из Telegram
- 🎨 Интерфейс в стиле **Material 3 Expressive**
- 📱 Оптимизировано для мобильного использования

## 🔒 Форматы шифрования

### SEC1

Режим совместимости со старыми сообщениями SecCrypt.

Используется для работы с сообщениями, созданными предыдущими версиями плагина.

### SEC2

Расширенный формат с проверкой целостности данных.

Позволяет обнаруживать изменение зашифрованного сообщения или повреждение его содержимого.

### SEC3

Современный формат SecCrypt с аутентифицированным шифрованием.

SEC3 использует **AES-256-GCM** для защиты данных и производный от парольной фразы ключ для повышения устойчивости к перебору пароля.

> Для новых сообщений рекомендуется использовать **SEC3**.

## 📦 Установка

1. Установите [exteraGram](https://t.me/exteraReleases).
2. Скачайте последнюю версию SecCrypt из раздела **Releases**.
3. Откройте файл `.plugin` через exteraGram.
4. Установите плагин.
5. Откройте настройки плагинов и убедитесь, что **SecCrypt** включён.

## 🚀 Использование

### Создание защищённого сообщения

1. Откройте интерфейс **SecCrypt**.
2. Выберите систему защиты:
   - `SEC1`
   - `SEC2`
   - `SEC3`
3. Укажите получателя.
4. Введите парольную фразу.
5. Введите сообщение.
6. Нажмите **«Зашифровать и отправить»**.

Получатель сможет расшифровать сообщение только при наличии правильной парольной фразы.

### Расшифровка

1. Откройте полученное защищённое сообщение.
2. Перейдите в интерфейс **SecCrypt**.
3. Введите парольную фразу.
4. Нажмите **«Расшифровать»**.
5. После успешной расшифровки содержимое сообщения будет показано в интерфейсе.

Формат сообщения определяется автоматически, когда это возможно.

## 🛡️ Безопасность

SecCrypt предназначен для защиты содержимого сообщений от прочтения без соответствующей парольной фразы.

**Важно:** безопасность зашифрованного сообщения напрямую зависит от качества используемой парольной фразы.

Не используйте простые пароли вроде:

- `123456`
- `password`
- `qwerty`
- имя пользователя
- дату рождения
- другие легко угадываемые значения

Для важных сообщений используйте длинные и уникальные парольные фразы.
